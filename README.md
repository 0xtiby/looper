# @0xtiby/looper

Standalone AI loop orchestration engine.

Looper iterates an AI CLI (claude, codex, opencode) against a prompt until a configurable sentinel is detected, max iterations are reached, or an error occurs. No opinions about specs, plans, trackers, git, or project structure.

## Status

Work in progress. See the [project PRD](https://github.com/0xtiby/looper/issues/1) and open issues for roadmap.

## Install

```sh
pnpm add @0xtiby/looper
```
